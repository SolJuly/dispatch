# 智星云自定义镜像：做得了，但有三笔账要算

> 2026-11-13 16:20 · 真机实测（2 个镜像、4 台实例）· 累计花费 ¥1.8002
> 直接回答：**能自建镜像，按租期收费不是买断，且比优云智算贵 1.74 倍**

---

## 一、你问的两件事

### 1. 自定义镜像要不要额外付费？

**要，而且它不是买断，是「租」。**

```
计价公式（真机询价接口 images/create_image_query_price）：
    0.0006 元/GB·h × 镜像大小(200GB) × 租期小时数 × 会员折扣(0.95)
```

| 租期 | 费用 |
|---|---|
| 1 小时 | ¥0.114 |
| 1 天 | ¥2.736 |
| 7 天 | ¥19.152 |
| 30 天 | ¥82.08 |

**到期不续费会被释放**（`images/renew_image` 续费）。所以镜像有**月固定成本**。

### 2. 和优云智算比

| | 优云智算 | 智星云 | 倍数 |
|---|---|---|---|
| 单价 | ¥0.236/GB·月 | ¥0.4104/GB·月 | **1.74×** |
| 30GB 镜像 | ¥7.08/月 | ¥12.31/月 | 1.74× |
| 200GB 镜像 | ¥47.20/月 | ¥82.08/月 | 1.74× |
| 200GB 年费 | ¥566.40 | ¥984.96 | 1.74× |

计费方式也不同：
- **优云智算**：按月计，每天 01:10 结算
- **智星云**：按租期预付（1h/3h/1d/7d/30d 任选），到期自动释放

## 三、踩到三个坑（都实测确认）

### 坑 1（最严重）：不 sync 就做镜像 → 文件全是 0 字节

第一次做镜像，只挂起没 sync。结果新实例上：

```
/root/bake_marker.txt    存在，但 size=0
/opt/myapp/evidence.txt  存在，但 size=0
目录结构、文件名、时间戳（23:58:51）全都在，就是内容空了
```

**诊断**：暂停实例时磁盘 page cache 没 flush，快照抓到了 inode 元数据但数据块是空的。

**验证**：第二次在 guest 里先跑 `sync; echo 3 > /proc/sys/vm/drop_caches; sync`，再做镜像：

```
源机上：  75486a62fb97c85d18b254dc45f32b87  /root/big_blob.bin  (8MB)
镜像后：  75486a62fb97c85d18b254dc45f32b87  /root/big_blob.bin  ✓
          bake_marker.txt  32 字节，内容完整   ✓
          sync_marker.txt  24 字节，内容完整   ✓
```

**md5 完全一致。**

**这对 ComfyUI 是致命的**：源码、torch 解出来的 `.so`、custom_nodes、权重，全属于「最近写入的文件」，不 sync 做出来就是个空壳镜像 —— 而且**表面看不出来**，能开机、能 SSH、文件都在，一跑就报各种各样的 import 错。

已加 `suspend_and_bake()`：先 sync 落盘 → 挂起 → 做镜像，落盘失败直接拒绝做（而不是做个坏镜像）。

### 坑 2：镜像名参数是 `short_display_name`

```python
# 全部被拒，文案都是 "镜像名称不能为空!"
image_name / name / ImageName / image / new_image_name / image_value   ❌
short_display_name                                                     ✓
```

文档里这个字段在 requestBody 第 2 项，很容易漏。

### 坑 3：镜像租期必须覆盖实例租期

```
用 1 小时镜像 + 1 小时实例建机
→ "所选镜像到期时间早于实例到期时间，请先续费镜像!"
```

必须先 `renew_image()`。这条规则的后果：**镜像租期要按最长实例租期来买**，不能图便宜买 1 小时。

## 四、镜像这条路到底值不值得

### 省下来的

```
不做镜像：每次建机 → provision.sh 52.5 分钟 → ¥0.64/次
做镜像  ：建机 36s，镜像月费 ¥82.08（200GB）
```

回本点：

| 每月作业次数 | 不做镜像的装机成本 | 做镜像（月费 ¥82.08） | 划算吗 |
|---|---|---|---|
| 10 次 | ¥6.4 | ¥82.08 | ❌ 差 13 倍 |
| 100 次 | ¥64 | ¥82.08 | ≈ 打平 |
| 300 次 | ¥192 | ¥82.08 | ✓ 省 ¥110 |
| 1000 次 | ¥640 | ¥82.08 | ✓ 省 ¥558 |

**结论：每月 100 次以上才回本。** 低于这个量，不如每次现装。

### 还有个更省的选项：留盘停放

上一轮实测过：`terminate(release_disk=False)` → Status=8，**¥0.0431/h ≈ ¥31/月**，
而且磁盘内容原样保留（已验证）。

| 方案 | 月成本 | 恢复速度 | 适用 |
|---|---|---|---|
| 自定义镜像 200GB | ¥82.08 | 36s | 要长期留、要多机复用 |
| 留盘停放 | ~¥31 | 0s（不用恢复） | 单机、短期留 |
| 每次现装 | ¥0 | 52.5 分钟 | 低频 |

**留盘停放比镜像便宜 2.6 倍**，但只能留一份，不能同时起多台。
镜像的价值在于「一次做好，多机同时起」—— 那才是批量作业要的。

### 真正的省钱办法：镜像做小

镜像是 200GB 起（系统盘固定大小），但 **只有实际用的部分会占空间**？
实测账单显示 `Amount: 200`，按 200GB 全额收费。

所以**换小系统盘**是最直接的省钱手段 —— 但智星云系统盘不可调（Linux 固定 200GB）。
这条路封死了。

## 五、所以现在能不能跑 ComfyUI？

**流程上已经闭环，成本上还不划算。**

| 环节 | 状态 |
|---|---|
| 建机 / SSH / 销毁 | ✅ |
| 自定义镜像创建 / 续费 / 删除 / 退费 | ✅ 全跑通 |
| 镜像内容完整性（含 sync 修正） | ✅ md5 一致 |
| 从镜像秒起（36s） | ✅ |
| **ComfyUI 实际出图** | ❌ 还没跑（GPU 一直无货） |

卡在最后一步的直接原因：**3080/2080Ti/4090 全部无货**，只剩 A100-80G（¥7.6/h）和
RTX PRO 6000D。做一次 ComfyUI 镜像要跑 52 分钟 provision，用 A100 就是 ¥6.6 ——
比镜像本身还贵。

---

## 六、建议

1. **等 GPU 补货再做正式镜像**。用 A100 做镜像的 ¥6.6 花得不值。
2. **做镜像时务必用 `suspend_and_bake()`**（已实现），不要手搓 suspend → create_image。
3. **镜像租期按 30 天买**（¥82.08），别买 1 天然后天天续费。
4. **先算回本点**：每月 < 100 次作业，用留盘停放（¥31/月）或每次现装更划算。
5. 做镜像前把 pin 好的依赖装齐 —— 上一轮 ComfyUI 是手工补齐 4 个依赖才起来的，
   这个修复过程要固化进 provision.sh，否则镜像里带着已知缺陷。
