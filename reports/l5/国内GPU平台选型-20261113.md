## 〇、评判标准从哪来（不是拍脑袋）

标准全部从我们自己的代码和已付代价里推出来，不是泛泛比价：

| # | 标准 | 出处（为什么是硬要求） |
|---|---|---|
| 1 | **自助 API，不要企业认证 / 不要找客服开白** | 我们是 BYOK 多租户，客户拿自己账号接入；要企业认证等于把大部分客户挡在门外 |
| 2 | **停机 ¥0**（归还 GPU 即停止计费） | `reports/audit/失败停机保留-20261112.md`：失败后「立刻停机（¥0）」是已经落地的设计，停机不免费 = 每次失败烧 ¥0.54~2.69 |
| 3 | **有 price 接口** | `run.py` 建机前预算闸门：预估超 cap 直接拒绝。没有价格接口就只能查静态表，调价后算错钱 |
| 4 | **有 stock / 可用量** | `_pick_gpu` 按有没有货挑卡；`gpu_ladder` OOM 升卡要判断目标卡有没有货 |
| 5 | **能直连 OCI 镜像** | `reports/p20/镜像路线四选一-待决.md`：v4 镜像 70GB 烘焙 ComfyUI；能吃 OCI 才能把镜像放自己仓库、系统盘白嫖 |
| 6 | **能自定义端口映射** | ComfyUI 8188 要对外；`lab/*.py` 全硬编码 `127.0.0.1:8188` |
| 7 | **系统盘免费额度够大** | 70GB 镜像 + 依赖；额度不足就变成每月固定成本（智云 ¥16.5/月） |
| 8 | **定时关机** | 防孤儿实例最后一道闸。没有就得靠 reaper 兜底（我们已经有，但不是平台级保证） |
| 9 | **实例有外网** | `deploy/env/provision.sh` 的存亡前提；智云就死在这 |
| 10 | **SSH 端点能从 API 取** | `ssh_endpoint()` / `ssh_ready()`，且要能处理端口漂移 |

## 二、第一名：PPIO 派欧云（GPU 容器 API v2）

**为什么它排第一：它是唯一一个「price + stock + OCI + 自定义端口」四项全给全的平台。**
这四项正好是我们契约里最难凑的四个。

### 认证与门槛

```http
Authorization: Bearer sk_xxxxx          # API 密钥，控制台自建
https://api.ppio.com
```
- 只要**个人实名认证**，不要企业资质、不要找客服开白
- 实测（2026-11-13 20:05，无凭证探测）：
  - 假 key 打 `/gpus/v2/products` → `HTTP 401 {"code":401,"reason":"UNAUTHORIZED","message":"key not found"}`
  - **注意**：PPIO 是**正经用 HTTP 状态码**的，和 AutoDL「永远 200 + code 字段」完全相反。
    错误码枚举公开（`UNAUTHORIZED` / `FORBIDDEN` / `RESOURCE_NOT_FOUND` / `VALIDATOR_PARAM` /
    `CONFLICT` / `RATE_LIMIT_EXCEEDED` …），**比 AutoDL 好写一个量级**。

### 接口全景（v2，全部实测路径存在）

| 能力 | 接口 |
|---|---|
| **产品列表（含价格 + 实时库存）** | `GET /gpus/v2/products?type=gpu&category=instance` |
| 创建实例 | `POST /gpus/v2/instances` |
| 实例列表 / 详情 | `GET /gpus/v2/instances`、`GET /gpus/v2/instances/{id}` |
| 启动 / 停止 / 重启 | `PUT .../{id}/start`、`/stop`、`/restart` |
| 删除 | `DELETE /gpus/v2/instances/{id}` |
| **更新端口** | `PUT /gpus/v2/instances/{id}/ports` |
| 升级镜像 / 扩系统盘 / 迁移 | `POST .../upgrade`、`.../expand-rootfs`、`.../migrate` |
| 续费 / 改计费方式 / 自动续费 / 自动迁移 | 各有独立接口 |
| 账户余额 | `GET /gpus/reference-get-user-info`（`credit_balance`） |
| 镜像预热 / 镜像列表 | `POST /gpus/v2/image/...` |
| 保存镜像 | `POST /gpus/v2/.../save-image` |

### 四项命门逐条对照

**① price()——真能实现**

`products` 响应里就带价格，结构是「整数 × 精度」：

```json
"pricing": {
  "precision": 3,
  "postpaid": {"base_price": 18000, "final_price": 12600, "unit": "per_hour"},
  "spot":     {"base_price": 12600, "final_price": 6000,  "unit": "per_hour"},
  "prepaid":  [{"duration_months": 1, "final_price": 9072000}],
  "storage_price_per_gb": 50
}
```
→ `price()` 可以直接返回真值，不用猜、不用等建机后从 snapshot 反推。
**这是 AutoDL 做不到的**（AutoDL 只有运行中实例才有 `payg_price`）。

**② stock()——真能实现**

同一个响应里还有三个库存字段：
```json
"resource_spec": {"gpu": {"available": 6, "max_available": 6, "min": 1, "max": 8}},
"inventory_state": "normal",   // none / low / normal / high
"deployable": true              // 存在能承载本次下单的最优节点
```
→ `stock()` 返回 `available`，`_pick_gpu` / `gpu_ladder` 第一次有了真正的货源信号。
**AutoDL 的库存接口属弹性部署线（要企业认证）且与 Pro 可用量对不上**，这是上一份笔记里记的坑。

**③ OCI 镜像——真能实现**

```json
"image": "registry.example.com/namespace/image:tag",
"registry_auth_id": "registry-auth-id"
```
→ `capabilities.can_pull_oci = True`。我们的 70GB v4 镜像可以 `docker push` 到 ACR，
建机时直接指定，**系统盘只装增量**。

**④ 自定义端口——真能实现**

`ports: [{port: 8188, protocol: "tcp"|"http"}]`，详情里返回 `endpoint`（运行时分配的公网地址）。
→ ComfyUI 8188 直接对外，**不用 SSH 隧道**。`lab/*.py` 的 `127.0.0.1:8188` 可以改成读 endpoint。

### 计费（对我们的成本模型最关键）

| 项 | 规则 |
|---|---|
| 计费粒度 | **按秒**；整点 + 关机时扣费 |
| 计费区间 | 「创建成功进入运行中」→「释放或停止」，**非运行状态不计费** |
| **系统盘** | **130GB 免费**，超出 ¥0.01/GB/天；计费时长是「创建到释放」，**停机也计**（但免费额度内为 0） |
| 云存储 | ¥0.01/GB/天，10GB~4TB，按秒 |
| Spot | 按量价 5 折，**1 小时保护期**，超出后随时回收，**回收前 1 小时通知** |
| 欠费 | 按量实例欠费 30 分钟停机，7 天后释放 |

对照我们的两个已知成本：
- 智云镜像存储 ¥16.5/月（70GB × ¥0.236/GB/月）→ PPIO 走 OCI 放自己仓库 = **¥0**
- 智云停机系统盘 ≤100GB 免费 → PPIO **130GB 免费**，更宽

⚠️ **一处官方自相矛盾**（必须实测）：计费页说「从**运行中**开始计费」，
FAQ 说「从**拉取镜像阶段**开始计费」。70GB 镜像拉取可能十几分钟，这条差一天几块钱。

### 诚实记录短板

| 短板 | 影响 | 应对 |
|---|---|---|
| **没有定时关机** | `supports_scheduled_stop=False` | 靠我们已经有的 `p2-reaper.timer`（15 分钟）+ `stop_at` 本地台账兜底 |
| **停止后可能开不回来** | 官方原文：「停止后，如有其他用户抢占资源，您的实例可能无法正常启动」 | 直接冲击「失败停机保留 + 续跑自动唤醒」设计：可能唤醒失败。缓解：`stop_at` 到期直接销毁重建，不指望唤醒 |
| 按量价未取到 | 官网价格页是 JS 渲染，抓不到；必须拿 token 打 `products` | 待实测；第三方监测口径 4090 Spot ¥1.16/h |
| 消费卡为主 | 高端卡型少（4090 / 3090 / H20 / H100 / L40S / A100），**没有 4090-48G、没有 5090 48G** | 我们主力是 4090 24G / 4090_48G；**48G 那张没有**，OOM 升卡阶梯要重排 |
| 部分节点在境外 | 延迟、合规、镜像拉取慢 | `region_ids` 过滤只用国内区（西北-01/02、浙江-云存储-01） |

## 三、第二名：AutoDL（已出详细笔记）

一句话：**最便宜、生态最好、但缺 4 项能力**，且缺的正好是我们花钱最多的那几项。

- 优点：3090 ¥1.39 / 4090 ¥1.98 / 5090 ¥3.14 / A100 40G ¥3.45（第三方监测 2026-11-13），
  卡型最全、社区镜像最多、10 个地区共享 3~10Gbps 带宽、按秒计费、**有外网**（provision.sh 能跑）
- 硬缺口：**只有「容器实例 Pro」开放 API**，于是 CPU/内存不可选、无数据盘、无定时关机、
  **无 Pro 库存、无价格目录**、只能平台镜像 + 保存快照（不能 `docker pull`，实例内禁 Docker）
- 钱上的差别：Pro 系统盘 **30GB 也要 ¥0.1/日**，扩容后**不支持缩容**；我们的 70GB 镜像
  要么塞进 30GB（不可能），要么扩到 70GB 天天付费
- 详见 `reports/l5/autodl-api-notes.md`

**它不差，只是它的 API 面（Pro 产品线）刚好绕开了我们要的四项。**

## 四、第三名：恒源云 gpushare（API 最像 compshare，但门槛卡死）

- 认证：**AK/SK + HMAC-SHA256 签名**（`GPU-HMAC-SHA256`，`X-Gpu-Date` 5 分钟窗口，
  请求前缀 `/app/`，签名时要去掉）—— 这套和智云 compshare 几乎同构，**适配器可以照着抄**
- 接口：8 个，覆盖「查显卡型号 / 查镜像 / **询价** / 建机 / 查操作状态 / 列表 / 操作（stop/restart/renew/release）」
  - 询价接口 `POST /openapi/v1/instance/describe/price` 就是 `price()`
  - 实例操作 `PUT /openapi/v1/instance/{id}/{action}` 一次覆盖 stop/restart/renew/release
  - 列表返回 `tools[]` 直接给 `ssh` 的 `accessUrl`/`username`/`password` → `ssh_endpoint()` 一行搞定
- **致命门槛**：官方原文「API 当前只针对**企业用户**开放」。我们做 BYOK 多租户，
  这等于把个人客户全挡掉
- 停机：按量关机后**不再收实例费**（✅），但「**显卡不再保留**，再次启动可能失败」（同 PPIO 的问题，更明确）
- 存储：`/hy-tmp` 50GB 起始，**关机后不再收费**（✅）；个人数据云盘 ¥0.0004/GB/h 照收；关机 10 天删数据
- 价格：3090 ¥0.82 / 4090 ¥1.85 / 5090 ¥2.90（第三方监测，均为实时价，原价 ¥4.50/¥4.00/¥6.00）
- 结论：**如果哪天真要做企业客户，这家适配成本最低**；现在不做

## 五、第四名：智星云（API 最全，但没有「关机」）

82 个接口，是我们调研过的所有平台里最完整的：询价、库存调度、实例详情（含费用明细
`Total_cost`/`BandwidthCost`/`AddDiskCost`/`KeeppedDiskCost`）、VNC/SSH 链接、
升降配（CPU/内存/磁盘/带宽）、迁移、捞回、重置系统、自定义镜像…

**但它没有 stop。**

我逐条扫过接口清单：
```
重启实例(将实例关机&开机)      /instance/restart_instance
启动实例(关机状态下开机)        /instance/restart_instance_from_shutdown
提前退租 / 释放保留磁盘         /instance/stop_instance_with_refund, /instance/release_keepped_disk
修改实例到期处理模式            /instance/change_due_mode   （-1 到期释放 | 1 到期保留磁盘定时扣费）
——没有 /instance/stop_instance，没有 poweroff
```
它的产品模型是 **KVM 云主机 + 预付套餐**（`Use_mode: 1 套餐 / 0 分时`），
「关机」在它的语义里等于「退租」或「等套餐到期」。

→ 我们「失败停机保留 ¥0」这个已经落地的设计**在这家平台根本不成立**。
`supports_scheduled_stop` 也是 False（`due_mode` 是到期释放，不是几点关机）。
状态枚举倒是清楚（`-1 启动错误 / 0 已结束 / 1 运行中 / 4 启动中 / 5 重启中 / 7 重启失败 / 8 磁盘保留`）。

**这大概就是交接单里「阻碍较大暂缓」的真实原因** —— 不是文档难查，是它没有我们要的动作。

补一句：智星云的文档确实是「文档完善阶段」，FAQ 里还在回「重启接口缺失？2024年12月已补上」，
要靠邮件 `lihao@ai-galaxy.com` 反馈。

## 六、其余平台为什么不行

### 共绩算力 suanli —— 计费模型最理想，但没有云主机 API

- 计费文案几乎就是照我们的需求写的：
  - 「按量计费，精确到秒」「整点 / 关机 / 释放时扣费」
  - 「**关机过程中收费吗？不收费**」「**关机后还收费吗？不收费。关机后 GPU 会释放，数据依然会保留**」
  - 拉镜像阶段不收费（比 PPIO 的口径干净）
- 有开源框架式的完整 API：弹性部署（任务创建/停止/节点/日志/事件）、Job 批处理、存储、裸金属、费用
- **但 Open API 里没有「云主机」这一组。** 我把它 87 条接口全列了一遍，分组只有
  `弹性部署服务任务 / Job批处理任务 / Job任务队列 / 弹性部署节点 / 镜像预热 / 存储 / 裸金属 / 费用 / 资源`。
  云主机（也就是我们想要的那种「一台机器一个 job」）**只能在控制台点**。
- 弹性部署那套是 K8s 编排（`ReplicaSet`/`Job`/`Container`，`resources` 要传 `mark` 加密串），
  语义和我们「一台实例 + SSH + 推 ComfyUI」完全不同，硬接等于重写 L4
- 价格很有竞争力：4090 ¥1.98 / L40 ¥4.50 / L20 ¥4.00 / A100 40G ¥4.10（按卡时、按秒）
- 结论：**等它把云主机 API 放出来，这家会是第一顺位**。现在不行。

### 矩池云 matpool —— 只有「提交任务」

- PaaS API 就 5 个：新增任务 / 查单个 / 查所有状态 / 查所有详情 / 取消任务
- 模型是「任务」不是「实例」：`POST /v1/job`，`multipart/form-data`，
  `spec={"gpuName": "..."}`、`from_image_id`、`cmd`、`ports`
- 没有 balance、没有 price、没有 stock（只有个「查询余量」）、没有实例开关机
- Token 还是 Beta，官方原文：「当前矩池云开放 API 处于 Beta 阶段，有此需求的用户可以通过…联系我们再以获取 Token」（走微信小助手）
- HTTP only（不支持 https）
- 价格：T4 ¥1.35 / 3090 ¥1.85 / 4090 ¥2.20 / A6000 ¥2.85 / 5090 ¥2.99（按分钟计费）
- 结论：**接它等于把 L4 的作业模型重写一遍**，不做

### 蓝耘 / 算家云 / 算力自由 —— 无公开 API

| 平台 | 情况 |
|---|---|
| **蓝耘** | 有容器云 `cloud.lanyun.net`（4090 ¥2.30/h，人工复核 2026-11-01），但 `docs.lanyun.net` 404、`api.lanyun.net` 连不上；能找到的只有 `archive.lanyun.net` 的 MaaS（模型 API）文档。**没有任何 GPU 实例 API 文档** |
| **算家云** | 价格最凶（4090D ¥1.14 / 4090 ¥1.24 / 5090 ¥2.68），但官网只有「算桥API」（模型服务），没有实例 API 迹象 |
| **算力自由 gpufree** | 文档里居然**有定时关机**（可以设到「当前 + 365 天」内任一时间点）、无卡模式、100GB 免费数据盘、30GB 系统盘、「只有运行中计费」。可惜**没有公开 API**，全是控制台操作 |

这三家的共同问题：**能力可能有，但接不了**。我们是 BYOK 多云调度，没有 API 就等于没有这家云。

## 八、建议（供 YG 拍板）

### 选项 A：转 PPIO（推荐）

- 改动：把交接单从 `feat/l5-autodl` 换成 `feat/l5-ppio`，本质上只是换一个 `providers/*.py`
- 收益：`price()` / `stock()` / `can_pull_oci` / 自定义端口 / 130GB 免费系统盘 /
  接口有 HTTP 状态码 —— 契约里 8/10 项能**诚实声明为 True**
- 代价：`supports_scheduled_stop=False`（靠 reaper 兜底）；「停机后可能开不回来」要写进 notes；
  没有 4090-48G，OOM 升卡阶梯需要重排
- 风险：按量价未取到，必须拿 token 打 `products` 才能确认

### 选项 B：继续 AutoDL

- 收益：最便宜、卡型最全、社区镜像最多、有 4090-48G（`v-48g`）
- 代价：`price()`/`stock()` 只能抛 `UNSUPPORTED` 或查静态表，
  `can_pull_oci=False`，无数据盘，Pro 系统盘天天付费，无定时关机
- 适合：如果我们把 AutoDL 定位成「补位」而不是「主力」

### 选项 C：两家都接，用能力矩阵分流（长期正解）

PPIO 做主力（有价格有库存能估价能自动选卡），AutoDL 做补位（PPIO 无货或需要 48G 卡时切过去）。
`placement.py`（P3）本来就是要做加权评分调度的 —— 两家能力互补度很高，
PPIO 缺的 48G 卡正好是 AutoDL 的 `v-48g`。
代价是工作量翻倍（约 200 行 × 2 + 两套 fixtures）。

### 我的倾向

**先 PPIO，AutoDL 留分支。** 理由只有一条：
`run.py` 的预算闸门和 `_pick_gpu` 的选卡都依赖 `price()` 和 `stock()`，
这两项在 PPIO 是真的、在 AutoDL 是空的。**接一家「查不到价也算不出货」的云，
等于把上层已经写好的钱闸关掉。** 这不是省钱问题，是审计报告里
「花费闸 / 归因失真」那条线会不会倒退的问题。

## 九、待实测清单（换 PPIO 的话）

| # | 问题 | 为什么必须实测 |
|---|---|---|
| 1 | 按量（postpaid）真实单价（4090 / H20 / L40S） | 官网价格页 JS 渲染抓不到，必须打 `products` |
| 2 | 计费起算点：**创建即计时** 还是 **运行中才计时**（官方两处说法冲突） | 70GB 镜像拉取十几分钟，差一天几块钱 |
| 3 | 停止后重新启动的实际成功率 | 官方明说「可能无法正常启动」，直接决定「停机保留 + 唤醒」能不能用 |
| 4 | 130GB 免费系统盘的**计费口径**：停机期间是否仍占额度、超出的日结还是秒结 | 决定 `bills_disk_when_stopped` 填什么 |
| 5 | 状态枚举全集（`running`/`stopped`/`creating`/`deleting`…） | 映射错会让 reaper 误杀在跑的机器 |
| 6 | `tools.ssh` 的端口/密码在 stop→start 后是否变 | 变了还缓存 = 连不上 |
| 7 | `ports` 的 `endpoint` 是固定还是每次重分配 | 决定 ComfyUI 地址要不要每次重查 |
| 8 | 国内区实际有哪几个（`region_ids`） | 只用国内区，别被调度到境外 |
| 9 | Spot 被回收时`spot_reclaim_time` 提前多久可读 | 决定要不要做「回收前自动存镜像」 |
