## 1. 为什么你的模式不构成"再次转租"

### 1.1 条款禁的是什么

《安全规则》第七条：

> 未经许可，您不得对 compshare优云智算产品及服务**再次转租**。

「转租」的法律结构是：**你从平台租 → 你再租给别人 → 你收租金差**。

三个要素缺一不可：
1. 你是承租人（合同相对方是平台）
2. 你是出租人（合同相对方是终端用户）
3. 你从中赚取租金差

### 1.2 你的模式三个要素全不满足

```
客户 ──自己开户──> 智云（算力合同在这里）
  │                   ↑
  │                   │ 算力费直接付给平台
  └──用你的软件──> 你的平台（只收服务费）
```

| 要素 | 你的情况 |
|---|---|
| 你是承租人吗？ | ❌ 不是。客户自己租的，合同在客户和智云之间 |
| 你是出租人吗？ | ❌ 不是。你没把任何算力租给客户 |
| 你赚租金差吗？ | ❌ 不赚。算力费 100% 进平台，你收的是软件/调度服务费 |

**你没有"再次转租"任何东西，因为第一次就不是你租的。**

### 1.3 一个类比

| 类比 | 是否违反「不得转售」 |
|---|---|
| 阿里云禁止转售 ECS，那么「帮你管理阿里云账号的运维公司」违法吗？ | ❌ 不违法，客户自己的账号 |
| 航空公司禁止倒卖机票，「帮你比价订票的 App」违法吗？ | ❌ 不违法，钱付给航司 |
| **智云禁止转租算力，「帮你调度多云跑 ComfyUI 的软件」违法吗？** | ❌ **不违法** |

你的角色是**工具提供方**，不是**二房东**。

## 2. 你还踩中了一条官方激励通道

查协议时发现的：智云有 [用户推荐计划](https://www.compshare.cn/docs/overview/member/userrecommendations) 和
[激励活动协议](https://www.compshare.cn/docs/overview/serviceagreement/incentive)，
这是**平台自己设计的、鼓励你带客户来开户**的机制。

### 2.1 返利规则（激励活动协议 2.1）

> （2）被邀请者注册完成实名后并产生实际消费（以出现首张现金消费订单为基准），
> 邀请者可得 **5 元算力赠金/人**（不支持提现）；
> （3）被邀请者在平台消费，平台将在次月末为您返还其**当月消费金额的 10%**
> 作为返利，**直接汇入您指定的银行卡账户**；
> （4）以被邀请者注册之日起以 **1 年**为有效返利期。

| 项 | 数值 |
|---|---|
| 拉新奖励 | 5 元算力赠金/人（不可提现） |
| **消费返利** | **10% 现金**，按月打银行卡 |
| 有效期 | 客户注册起 1 年 |
| 起付线 | 当月 ≥¥20 才打款，不足累计到下月 |
| 税费 | **平台承担**（当前政策） |
| 结算节奏 | 次月 3 日前更新明细，次月末打款 |

### 2.2 还有镜像收益（2.2）

> 当您的镜像被其他用户使用，您将获得相应的收益……**长期收益，现金返还**

你那个 `p2-comfy-media-v4` 如果发布到社区，别人用它建机，你也有收入。

### 2.3 这两条叠加起来，你的商业模式变成

```
收入 1：调度软件服务费（向客户收）        ← 你原本的设计
收入 2：客户在智云消费的 10% 返利        ← 平台的官方激励
收入 3：社区镜像被使用的收益（可选）      ← 平台的官方激励
```

**收入 2 和 3 不需要任何"授权"——平台自己就是发起方。**
这是「渠道」模式在智云上唯一完全合法的入径。

## 3. 但有三个硬限制（激励活动协议）

### 3.1 只能个人/高校用户申请

**2.7 原文：**

> 推广者和镜像创作者**仅限个人用户和高校用户，企业用户不可申请**。
> 如推广账号由个人/高校认证变更为企业认证，在完成企业认证前的推荐返利和
> 镜像收益将正常结算，**企业认证完成后产生的返利及镜像收益将不予结算**；
> 优云智算（前）员工、与优云智算有合作关系的销售工作人员及代理商，
> 不能成为推荐者。

**这条很要命**：

| 你的认证类型 | 能否拿返利 |
|---|---|
| 个人认证 | ✅ 能 |
| 高校用户 | ✅ 能 |
| **企业认证** | ❌ **不能**，且之前的也不给 |

**如果你以后要把这个做成公司，一旦企业认证，返利断了。**

### 3.2 "新用户"定义排除了已接触过平台的人

**1.3 原文：**

> 新用户：通过点击推荐者的邀请链接注册优云智算账户。**不包括**：
> （1）已有优云智算账户的用户；
> （2）已与优云智算销售人员、合作伙伴以及渠道代理商有接洽的用户；
> （3）与该推荐者被判定为同一用户的（同一证件、同一手机号、同一支付账号、
> 同一设备、同一地址等）。

**实操影响**：

- 已经是智云老客户的用户 → 你拿不到返利
- 你帮客户注册完，如果判定和你"同一地址/设备" → 不算新用户

### 3.3 平台可随时改规则

**2.3 原文：**

> 优云智算有权根据自身运营安排，**自主决定和调整本活动的具体规则**，
> 包括但不限于活动持续时间、**奖励比例**、奖励计算基础、推荐者申请资格……
> 相关规则一经公布即产生效力。

**10% 不是承诺，是当前政策。** 不能把它当长期收入模型的基础。

## 4. 真正要小心的三个坑（实操层面）

条款层面你安全，但落地时有三个地方容易踩：

### 4.1 🔴 别碰客户的 API Key 明文

你的 BYOK 要客户填 `CS_PUBLIC_KEY` / `CS_PRIVATE_KEY`。

- 《安全规则》没有直接管这个
- 但**《用户协议》第七条**禁止账户转让——你如果代客户登录、代管凭证，可能被认定"账户共享"
- 更现实的风险：**你泄露了就赔不起**

**正确做法**：

| 方案 | 做法 | 风险 |
|---|---|---|
| 🟢 推荐 | 客户在自己机器上跑你的软件，Key 不出他的机器 | 最低 |
| 🟡 可以 | 客户授权后加密存服务端，用 KMS | 中（要做加密 + 审计） |
| 🔴 别做 | 明文存数据库 / 明文写日志 | 出了事全责 |

### 4.2 🟡 你的"服务费"定价要能解释

平台或监管可能问：你收的到底是什么钱？

| 说法 | 能否站住 |
|---|---|
| "调度多云 GPU 的技术服务费" | ✅ 能，有实际交付物（调度、故障转移、缓存管理） |
| "算力差价" | ❌ 不能，那就是转租 |
| "按 GPU 小时数的 xx%" | 🔴 危险，价格与算力直接挂钩，会被认定为转租 |

**建议定价方式**：

```
✅  订阅制：¥99/月 · 不限作业数
✅  按作业计费但价格固定：¥2/作业（不论跑 30 秒还是 5 分钟）
🟡  按作业计费但按档位：小/中/大 三档（有解释空间）
🔴  按 GPU 秒数 × 单价：直接踩线
```

**核心：你的价格要能解释成"服务能力"，而不是"算力用量"。**

### 4.3 🟡 客户素材的合规责任在你这边

《安全规则》第二条列了一长串禁止内容（色情、暴力、政治敏感……），
而且第八条说「**停用含有违规内容的产品**」「**冻结用户账户**」。

**关键**：如果客户用你的软件在智云上跑违规内容，**被冻结的是客户的智云账号**，
但也可能连累你（如果你是推荐者，你的返利账户也在这个平台上）。

**要做的**：

- 用户协议里写明禁止用途
- 上传内容做基本过滤（至少拒绝明显违规）
- 保留作业日志，出事能自证
- 别让客户用你的软件当"匿名 GPU 出口"

## 7. 一句话

**你的模式不构成"再次转租"——因为第一次租的人不是你。**

算力合同在「客户 ↔ 云平台」之间，你只卖调度软件。
《安全规则》第七条管的是「你租了再租给别人」，你不在这个射程内。

**而且智云有官方 10% 现金返佣**，这是平台自己设计的带客通道，
走这条路你不但合规，还多一份收入。

**真正要小心的是三件事**：
1. **企业认证会断掉返利**（现在拿返利就别急着企业认证）
2. **Key 别明文存**（客户凭证泄露你赔不起）
3. **定价别按 GPU 秒数算**（那会把"服务费"变成"租金差"）
