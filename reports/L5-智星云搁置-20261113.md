## 一、结论先说

**接入本身是通的** —— 建机、SSH、销毁、留盘停放、自定义镜像全部真机验证过。
停下来的原因是**算不过账**，不是跑不起来。

| 硬指标 | 结果 | 判断 |
|---|---|---|
| 建机 → SSH | 36-41s | 可用 |
| 外网（DNS/pypi/docker） | 全通 | 比智云强 |
| ComfyUI 装机 | **52.5 分钟** | 致命 |
| 自定义镜像存储 | **¥0.4104/GB·月**（智云 ¥0.236） | 贵 1.74 倍 |
| 留盘停放 | ¥0.0431/h ≈ ¥31/月 | 比智云停机的 ¥0 贵 |
| 建机后销毁冷却 | **约 310s 内必然失败** | 短作业吃亏 |
| 停机 | 租期照常计费 | 等于没有 |

**一句话**：每跑一张图要多付 52 分钟装机或 ¥82/月镜像费，而智云靠预烘焙镜像 +
`/model` 免费挂载把这两项都归零了。

## 二、已做的停机动作（四层，都验证过）

### 1. 云侧资源清零

```
实例：13 台，全部 Status=0 terminated，磁盘已释放
镜像：2 个测试镜像已删除，退费 ¥2.7163 + ¥2.8379 = ¥5.55
在跑的：0
```

### 2. 适配器层硬拦截

在**唯一的请求出口** `call()` 上拦截，覆盖建机/销毁/询价/镜像/余额全部能力：

```python
if not (ENABLED or self._test_unlocked):
    raise ProviderError(DISABLED_MSG, ProviderError.UNSUPPORTED)
```

`ENABLED` 默认 False，需显式 `ZXY_ENABLE=1` 才放行。
`_test_unlocked` 只在注入了假 transport（离线测试）时才为 True —— 那种情况根本发不出真请求。

### 3. 注册表摘除

```python
_BUILTIN = ("compshare", "local", "fake")   # zhixingyun 拿出来了
_SUSPENDED = ("zhixingyun",)                 # 单独列出，工厂入口直接拒
```

`available()` 现在返回 `['local', 'fake']` —— 巡检类工具（cost_snapshot）
不会再把它当可查对象去请求真实云。

> 踩过一个坑：`_SUSPENDED` 判断最初写在 `if name == "zhixingyun"` 分支**之后**，
> 永远走不到，`get_provider("zhixingyun")` 照样能拿到实例。已挪到最前面。

### 4. 凭证隔离

```bash
.zxy/credentials.env  →  .zxy/credentials.env.suspended
```

改名而非删除：适配器只读 `credentials.env`，改名后连「误启用时能找到凭证」
这条路也断了。同目录留了 `.header` 说明恢复三步。

## 五、下次要重启这条线，先想清楚这几件事

1. **回本点**：每月作业 < 100 次，自定义镜像不划算（月费 ¥82.08 vs 每次装机 ¥0.64）。
   低频场景用留盘停放（¥31/月）或每次现装。

2. **必须先修 provision.sh 再打镜像**。这轮发现它有两个会让整条流程静默失效的 bug：
   - clone 失败却打印 `✓ 已克隆并检出`（留下空目录继续跑）
   - `constraints.txt` 路径拼成 `//docker/...`，pip 静默跳过版本约束

   两个都修了，但如果要打正式镜像，还得把 ComfyUI 的依赖补齐过程固化进去 ——
   这轮是手工补了 `alembic / blake3 / pydantic 2.x / comfy_aimdo.__init__` 才启动成功的。

3. **打镜像必须 sync**。这轮实测：不 sync 做出来的镜像，文件全变 0 字节
   （文件名/目录/时间戳都在，内容空）。已实现 `suspend_and_bake()` 自动化这一步。

4. **权重方案没解**。智云有 `/model` UPFS 40T 免费只读；智星云的 shareddisk
   是付费商品。没有 `sync` 可以绕，没有 `/model` 就绕不过 —— 这是两地跑同一份作业
   配置的最大障碍。

5. **短作业多吃 5 分钟**。建机后约 310 秒内退不掉，秒级作业要多付约 5 分钟算力费。
