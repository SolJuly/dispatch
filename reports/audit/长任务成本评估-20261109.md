### 1.3 路径 C 什么时候才划算

```
C 相对 A 省下的 = (113 - 7) × ¥2.15/h = ¥0.063
```

## 3. 长任务过程中到底有多少空转

你问的是「长任务时保证没有更多消耗」。我查了长任务的真实时间线。

### 3.1 长任务（推理 443–641 秒那批）

```
p1-20261107T1143-051e66   装载 116s · 推理 641s · 总计 763s
p1-20261107T1149-5d0b4a   装载 117s · 推理 462s · 总计 583s
p1-20261107T1059-964dee   装载 115s · 推理 484s · 总计 613s
```

**长任务里没有"空转"** —— 从提交到推理完成，GPU 一直在跑。
唯一的固定开销是开头那 115 秒装载，这是不可避免的（除非复用）。

### 3.2 但长任务有个隐藏成本：**超时等待**

看 `step_wait` 的实现：

```python
while time.time() - t0 < limit:
    rc, out = _ssh_run(...)      # 每 5 秒查一次 history
    if rc == 0:
        if st == "success": return files
    ...
    time.sleep(5)
```

**每 5 秒一次 SSH 查询** —— 推理 641 秒 = 128 次 SSH。这个开销很小（不进 GPU），
但有个更实际的成本：**如果作业卡住（GPU 在跑但没产出）**，
一直等到 `max_minutes`（默认 20 分钟）才放弃。

### 3.3 真正的空转风险在"失败后保留实例"

```python
KEEP_MINUTES = 15          # 失败后实例保留时长（到点自动关机）
```

失败后实例留 15 分钟等人工 `--resume`。**15 分钟 × ¥0.036 = ¥0.54** ——
这比一次装载贵 8 倍。

**这才是长任务场景下真正该压缩的空转。**

## 4. 修正后的方案

### 4.1 撤回「10 分钟窗口」

按盈亏平衡，10 分钟是错的数量级。改成**分档**：

| 场景 | 窗口 | 理由 |
|---|---|---|
| 队列里还有同模型待跑作业 | **不关**（规则 B 让路） | 下一单马上就来，关掉要重装 |
| 队列空、刚跑完 | **90 秒** | 覆盖"用户接着点第二条"的常见间隔，成本 ¥0.054 < 装载 ¥0.068 |
| 确实没人用了 | reaper 兜底 **5 分钟** | 从原来的 10 压到 5，省一半 |

**90 秒这个数**：`0.068 / 0.036 = 1.9 分钟` 是盈亏平衡，
取 90 秒留一半安全边界。超过 90 秒就停机（不是销毁）。

### 4.2 关键改动：销毁 → 停机

这是真正的杠杆，我上一轮没抓住：

| | 销毁重建 | **停机 + start** |
|---|---|---|
| 到能提交 | 113s | **62s**（省 45%） |
| 成本 | ¥0.067 | **¥0.037** |
| 停机期间 | — | **¥0（实测 11.5 小时）** |
| 环境 | 全新，要 setup 全套 | **烘焙快路径 5s** |

**停机省一半时间、成本减半，而且停机期间完全免费。**

上一轮 `reaper` 默认已经是 `stop` 不是 `terminate`（这点对了），
但 `run.py` 的 `step_release` 还是销毁 —— **这条没改到**。

### 4.3 修正后的生命周期

```
作业 DONE
  ↓
队列里还有同模型作业？
  ├─ 有 → 归还槽位，机器留着（下一单 ~10s 就能提交）
  └─ 无 → 暂停 90 秒（给"用户接着点第二条"留窗口）
            ├─ 90 秒内有新作业 → 复用
            └─ 90 秒后仍空闲 → 停机（不是销毁！）
                                  ↓
                            有作业来了 → start（57s，¥0.034）
                                  ↓
                            停机超 24h 都无作业 → 销毁（省配额）
```

### 4.4 短任务的公平性怎么保证

你的核心担忧。按修正后的设计：

| 场景 | 之前（10 分钟窗） | 修正后（90 秒窗 + 停机） |
|---|---|---|
| 跑一条就再也不用了 | 白烧 10 分钟 ¥0.36 | 90 秒 ¥0.054，然后停机 ¥0 |
| 跑完 5 分钟后回来 | 白烧 5 分钟 ¥0.18 | 已经停机，起来 57s ¥0.034 |
| 跑完马上再跑一条 | 复用，省 118s | 复用，省 118s |

**短任务的浪费从 ¥0.36 降到 ¥0.054，降 85%。**
