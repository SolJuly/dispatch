```
¥0.236/GB/月，每天 01:10 结算
70GB × ¥0.236 = ¥16.5/月
```

（起机不额外收），不是存储费。存储费单独按天结。

## 今天的实测补充了这一条

原报告 `23-镜像存储费与零成本路线.md` §6.1 把「v0.43.0 的 torch 版本未知」
列为**最大风险**，说「如果平台 v0.43.0 是 torch 2.10+cu130，自定义节点 ABI
可能不兼容（v3→v4 迁移时踩过 Autogrow 的坑）」。

**2026-11-12 实测：确实是 2.10.0+cu130。**

```
0.43.0 底座实例:  torch 2.10.0+cu130
v4 镜像:          torch 2.8.0+cu128
```

但**兼容性本身仍未验证** —— 只确认了版本差异存在，没验证节点在这种差异下
计不计算得对。要回答只能跑真实推理。
