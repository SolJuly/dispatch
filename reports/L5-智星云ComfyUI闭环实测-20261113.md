## 三、三个硬缺口（都实测确认）

### 缺口 1：没有 ComfyUI —— 装机要 52 分钟

智云靠**预烘焙镜像** `comfyuiImage-*`（`IMAGE_KEYWORD = "ComfyUI基础镜像纯净版0.36.0"`）。
智星云只有裸 Ubuntu，必须现装。

实测 `provision.sh` 完整跑一遍：**3149 秒 = 52.5 分钟**，这还不含 torch（我先装好了）。

```
torch 2.8+cu128 全家桶   ~12 分钟（2.5GB，3.5MB/s）
ComfyUI 克隆             3 重试后才成功（第一次被 CANCEL err 8 打断）
custom_nodes × 10        ~20 分钟（clone + pip 依赖）
软依赖（gui 库等）        ~20 分钟
```

**这 52 分钟照常计费：¥0.64。** 而智云开机 95s 就能跑。

### 缺口 2：没有 `/model` 权重

manifest 写得很清楚：

```json
"models": {
  "strategy": "external",
  "note": "权重不进镜像。智云用 /model UPFS 40T 只读挂载；其它云挂 NAS/OSS/COS 到 /model"
}
```

智星云的 `shareddisk` 是**付费挂载商品**，不是智云那种免费的 40T 只读库。
所以就算 ComfyUI 起来了，**也没有模型可加载** —— 这一条是生图的硬前提。

### 缺口 3：pip 依赖装不全（comfyui 0.36 的新依赖链）

`docker/constraints.txt` 锁 `triton==3.6.0`，而机器是 anaconda 环境、`torch 2.8.0+cu128` 已装，
pip 解析直接 `ResolutionImpossible`，然后**整条 requirements 都没装**：

```
ERROR: Cannot install torch==2.8.0+cu128 because these package versions have conflicting dependencies.
ERROR: ResolutionImpossible
```

连带后果：`alembic`、`blake3`、`pydantic 2.x`、`comfy_aimdo.__init__` 全缺，
启动时一个个报错，我逐个手工补了 4 轮才起来。

## 四、顺手修掉的两个 provision.sh 真 bug

这两个 bug 不只影响智星云 —— 它们会让**任何**非智云环境悄悄装出一个坏环境。

### bug #1：clone 失败却打印「✓ 已克隆并检出」

```bash
run git clone "$COMFY_REPO" "$COMFY_HOME"    # run 不看退出码
run git -C "$COMFY_HOME" checkout -q "$COMFY_COMMIT"
ok "已克隆并检出 $COMFY_COMMIT"                # ← 无条件打印
```

实测第一轮就是这样：clone 被 `CANCEL (err 8)` 打断，`ComfyUI` 只剩一个空壳，
但日志写着 `✓ 已克隆并检出`，脚本继续往下把 10 个 node 全装进空目录，
**直到最后启动时才暴露成「main.py 不存在」**。

已修：`clone_retry()` 三次重试 + `must()` 检查退出码 + `[[ -f main.py ]]` 证明成功。

### bug #2：constraints.txt 路径算错

```bash
CONSTRAINTS="$ROOT/$(mf python.constraints_file 'docker/constraints.txt')"
```

直接 scp 脚本到机器上跑时，`$ROOT` 退化成 `/`，拼出 `//docker/constraints.txt`。
日志证据：

```
ERROR: Could not open constraint file: [Errno 2] 没有那个文件或目录: '//docker/constraints.txt'
```

后果是 pip **静默跳过版本约束**，装出与智云镜像不一致的依赖。
已修：按「脚本同目录 > 仓库根 > 环境变量」三级查找，并加 `CONSTRAINTS_FILE` 覆盖口。

> 这两个 bug 在智云上看不出来 —— 因为智云根本不用 provision.sh（无外网）。

## 五、成本对比（核心结论）

### 单次作业成本

| 项目 | 优云智算 | 智星云 |
|---|---|---|
| 装机 | **¥0**（预烘焙镜像） | **¥0.64**（52.5 分钟 × ¥0.73/h） |
| 权重 | **¥0**（/model UPFS 40T 免费只读） | 要下载/挂载（未测，但至少几 GB 流量 + 时间） |
| 开机到能跑 | **95s** | **3149s + 镜像下载时间** |
| 实例单价（3080 级） | 需查实时价 | ¥0.7315/h |
| **跑一张图的边际成本** | 纯算力时间 | 纯算力时间 + 上面这些固定开销 |

### 关键比值

```
装机时间   3149s / 95s  = 33 倍
装机费用   ¥0.64 / ¥0    = 有 vs 无
```

**这意味着：短作业在智星云上是亏的。** 跑一张 SDXL 图假设 20 秒，
智云总成本 ≈ 20 秒算力；智星云总成本 ≈ 52 分钟装机 + 20 秒算力。

只有当**一次建机跑很多作业**（批量几十上百张）时，52 分钟的固定开销才被摊薄。

### 破局办法：自定义镜像

智星云 **4.0 自定义镜像**接口齐全（创建/续订/退订/重试）。正确路线是：

```
第一次：建机 → provision.sh（52 分钟）→ 装好 ComfyUI + 权重 → 做成自定义镜像
以后  ：从自定义镜像建机 → 开机即用（预计 ~60s）
```

这条路线**我还没测**（要花一次 52 分钟 + 镜像存储费），但接口已确认存在。

## 六、所以现在到底能不能跑？

**分层回答：**

| 环节 | 状态 |
|---|---|
| 建机 / SSH / 销毁 | ✅ 闭环（已测 10 台） |
| GPU 驱动 / CUDA / torch | ✅ 可用（driver 550.78 / CUDA 12.4 / torch 2.8） |
| ComfyUI 装得上 | ✅ 能（52 分钟） |
| ComfyUI 启动 | ✅ 能（补齐 4 个依赖后） |
| **生成一张图** | ❌ **没验证到**（缺权重 + 前端资源下载太慢） |
| **生成一段视频** | ❌ **完全没测**（视频模型权重几十 GB，缺 /model 更致命） |

**离真正闭环还差：**
1. 权重怎么来（下载 / OSS 挂载 / 共享盘买）—— 必须定
2. 自定义镜像做一次，把 52 分钟摊掉 —— 必须做
3. 前端 339MB 的下载为什么要 15-400kB/s —— 网络问题要查

---

## 七、建议

**先别急着在智星云上跑生产。** 按这个顺序推进：

1. **做一次自定义镜像**（成本约 ¥0.7 + 存储费），把装机时间从 52 分钟压到 ~1 分钟。
   这是智星云能不能用的**分水岭** —— 不做这一步，它永远比智云贵 33 倍。
2. **解决权重**：优先试 OSS/COS 挂载到 `/model`（保持与智云同一路径，作业配置零改动）；
   或者试智星云的 shareddisk 挂载，先算清 ¥0.0006/GB·h 的总账。
3. **跑通一张 SDXL 图**，量出真实出图时间，再算边际成本。
4. 视频任务（Wan/H3）权重几十 GB，**在权重方案定下来之前不要碰**。
