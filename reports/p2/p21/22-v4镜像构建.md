## 2. 构建过程与踩的坑

| # | 问题 | 处理 |
|---|---|---|
| 1 | base 自带 ComfyUI v0.3.75（2025-11-26），KJNodes 报 `comfy_api.latest._io has no attribute 'Autogrow'` → IMPORT FAILED | 把核心升到 v3 同款 `3c80da7f`（2026-09-18），节点立刻恢复 |
| 2 | Impact-Pack 的 `sam2` 是 `git+https://github.com/facebookresearch/sam2`，pip 会在隔离环境装 torch，卡 10 分钟+ | 过滤 `git+`/`sam2` 行，只装 PyPI 依赖 |
| 3 | `models/vae/ae.safetensors` 是指向 HiDream 的**断链**（文件不存在），Z-Image 报 `FileNotFoundError` | 重指到 `z_image_turbo/split_files/vae/ae.safetensors` |
| 4 | Z-Image 的 unet/clip/vae 在 `/model` 里路径不同，P1 旧图用裸文件名找不到 | 建 3 条软链：`z_image_turbo_bf16` / `qwen_3_4b` / `ziamge_ae` |
| 5 | Wan 2.2 I2V 的静态图写的是 `wan2.2_i2v_high_noise_14B_fp8_scaled.safetensors`，实际在 `Wan_2.2_ComfyUI_Repackaged/` 下 | 补前缀后通过 |

> 结论：**v3 能跑不是因为这些图对，而是镜像里早就烤好了软链**。v4 把这些软链显式建出来并在文档里记下；后续应补进模型卡的 `setup.links`，别再依赖镜像。
