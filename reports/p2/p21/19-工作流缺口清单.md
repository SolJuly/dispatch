## 3. 真正的难点（按难易排序）

1. **不是缺权重，是名字不对**（占大头）
   `/model` 是只读 UPFS，平台镜像里的文件名五花八门：`wan2.1_14B_SCAIL_2_fp16` vs pack 的 `wan2_1_14b_scail_2_fp16`、`ltx-2.5-22b-distilled-transformer-comfy-int8-convrot` vs `ltx_2_5_...`。
   要做的是**建一张“pack 名 → 真实路径”映射表 + `setup.links`**，不需要下载。Qwen Edit 2509 已经用这个套路跑通。
2. **模板 API 图是 UI 导出的，动态 widget 会丢**
   SeedVR2 的 Loader 下拉、`ResizeImageMaskNode` 的 `resize_type`、VACE 的 `LatentCut/Concat` 参数都在导出时丢了。要么从 UI 重新导出，要么照对象 schema 手搭。S2V/Animate2/VACE/LTX 都卡在这。
3. **核心节点缺失（Qwen 2.1）**
   `QwenImage21Cache` / `TextEncodeQwenImage21` 不在 0.36 镜像里，要升 ComfyUI 核心；升完还要回归 1757 个 class 的兼容性，风险最高。
4. **镜像工程的容量问题**
   视频权重动辄 15–40GB，全烤进镜像就是每版 210GB+；`/model` 又只读。要么每次作业下载（每条多 2–5 分钟 + 流量），要么做“按需下载/缓存”机制——目前没有这个 hook。
5. **私有配置 / 目录注册（SUPIR、facegen）**
   SUPIR 的 `ModelPatchLoader` 没暴露文件输入；facegen 的 `ultralytics_bbox` 目录没注册。这两个是节点包自身的问题，改图解决不了。
