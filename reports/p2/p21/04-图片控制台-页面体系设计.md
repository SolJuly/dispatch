# 图片控制台 · 页面体系设计

> v1 · 2026-11-02 · 决策：**做完整页面体系**（不是最小控制台）
> 约束：仓库没有前端构建链（Python 3.10 标准库 + 服务端渲染 HTML + 原生 JS），不引入 npm/CDN 依赖
> 归属：M1 骨架与创作台（t2i）→ M2 图生图 → M3 局部重绘 → M4 图库/分享/收尾

---

## 1. 设计原则

| 原则 | 具体做法 |
|---|---|
| 零构建 | 服务端渲染 HTML 骨架 + `/static/app.css` `/static/app.js` 两个静态文件；JS 用原生 ES module，不打包 |
| 渐进增强 | 无 JS 时表单仍可提交（`<form method=post>` 回退），有 JS 时走 fetch + 轮询 |
| 单一数据源 | 页面数据全部来自既有 `/api/p2/*` 与新增写接口，页面不直读 SQLite |
| 失败可见 | 每个异步动作都有 loading / 空态 / 错误态三件套；错误文案带 `job_id` 与下一步动作 |
| 与 token 制共存 | 内部页面走 `/{token}/app/...`；分享页走签名链接 `/{token}/share/<job_id>?sig=`，可不暴露主 token |
| 图片优先 | 结果区永远优先于参数区；宽屏左参数右结果，窄屏参数折叠 |

## 2. 信息架构

```
/{token}/app                      创作台（默认 = 文生图）
/{token}/app/create?mode=t2i|i2i|inpaint
/{token}/app/jobs                 任务列表
/{token}/app/jobs/<job_id>        任务详情
/{token}/app/gallery              图库
/{token}/app/registry             工作流与模型（只读）
/{token}/share/<job_id>?sig=...   公开分享页（无主 token）
```

导航（全局顶栏）：**创作 · 任务 · 图库 · 工作流与模型**，右侧常驻：队列深度、余额、GPU 实例数、通知。

## 3. 页面规格

### 3.1 创作台 `/app/create`

三 tab 共用一套骨架，参数面板随 mode 切换。

| 区域 | 内容 |
|---|---|
| 左栏 · 模型 | `工作流` 下拉（按 `kind=image` 过滤）、`模型` 下拉（由 workflow 的 model key 决定，只读展示）、版本徽章（`v2`）、兼容性状态徽章（verified/equivalent/experimental） |
| 左栏 · 参数 | prompt（多行、字符计数）、negative prompt（折叠）、seed（数字 + 🎲 + 🔒 固定）、宽×高（预设 1:1 / 3:4 / 4:3 / 16:9 + 自定义，16 对齐校验）、steps、cfg、sampler（下拉）、scheduler（下拉）、batch（1–4 分段控件） |
| 左栏 · 提交 | 预估费用与预计时长（来自 workflow `limits` + 历史 P50）、`提交` 主按钮、`存为预设` |
| 右栏 · 结果 | 结果网格（1–4 张，等比卡片）、每张：放大 / 下载 / 复制 seed / 用作图生图输入 / 用作局部重绘底图 |
| 右栏 · 状态 | 状态机进度条（CREATED→…→DONE）、当前步骤、已用时、实例与 GPU、失败原因卡（含重试按钮） |
| 底部 | 最近 10 条作业的横向条（点击进详情） |

模式差异：

- **t2i**：无输入图。
- **i2i**：上传区（拖拽/选择，≤20MB，PNG/JPEG）、`denoise` 滑杆（0–1，默认 0.55）、结果区右侧出现**对比视图**（左原图右结果，中间滑杆）。
- **inpaint**：底图 + 蒙版画布（画笔/橡皮、笔刷大小、撤销、清空、反选）、`denoise`/重绘强度、结果区默认开启"保留区高亮比对"。

### 3.2 任务列表 `/app/jobs`

| 区域 | 内容 |
|---|---|
| 筛选栏 | 状态（全部/DONE/FAILED*/RUNNING）、工作流、模型、时间范围、关键词（job_id/prompt） |
| 表格 | job_id、缩略图、工作流@版本、模型@版本、状态、耗时、成本、创建时间、操作（详情/重跑/下载） |
| 分页 | 游标分页，每页 20；URL 带 query 便于回退 |
| 批量 | 勾选 → 批量下载 zip、批量重跑（同参数） |

### 3.3 任务详情 `/app/jobs/<id>`

| 区域 | 内容 |
|---|---|
| 头部 | job_id、状态徽章、工作流@版本、模型@版本、params_hash 前 12 位、耗时、成本 |
| 时间线 | 状态机 15 态的进入时间（`state_seq` + `steps`），失败态标红并给原因 |
| 参数快照 | 最终生效参数（含默认值来源标记：显式 / 默认 / registry） |
| 产物 | 网格 + 逐张下载 + 全部打包下载 |
| 追溯 | `model.workflow_sha256`、`rendered_graph` 折叠查看、ledger 记录、manifest 下载 |
| 操作 | 重跑（同参）、重跑并改参、复制分享链接 |

### 3.4 图库 `/app/gallery`

- 瀑布/等高网格（每行 4–6 张），按 job/日期分组。
- 筛选：模型、工作流、分辨率、时间；排序：时间/成本/耗时。
- 卡片：图、尺寸、seed、模型徽章、下载。
- 批量：选择 → zip 下载；两图勾选 → 并排对比。
- 空态：引导去创作台。

### 3.5 工作流与模型 `/app/registry`

- 工作流卡片：key@version、kind、node 数、参数表（类型/默认/范围/绑定节点）、兼容性矩阵、最近使用。
- 模型卡片：key、family、files（槽位/文件名/大小/可读性）、约束、setup profile。
- 只读，复用 `/api/p2/registry/*`；`incompatible` 组合标红并说明原因。

### 3.6 分享页 `/{token}/share/<job_id>?sig=...`

- 无需登录，只显示该作业的产物与参数摘要，不暴露其他作业、不暴露路径。
- 支持批量下载 zip；`sig` 为 `hmac(secret, job_id)`，可撤销（改 secret）。

## 5. 交互状态机（提交链路）

```
idle → validating → submitting → polling(1.5s, 退避到 5s) → done | failed | timeout
                 ↘ 参数错误（就地标红，不发请求）
```

- 轮询上限 30 分钟（与 `budget.max_minutes` 一致），超时提示去任务页查看。
- 失败态展示 `FAILED_*` + 原因 + `重试`（新 job，参数不变）+ `改参重试`。
- 页面关闭不丢作业：job 已在后端落盘，回到任务列表可见。

## 6. 接口契约（新增部分）

| 方法/路径 | 入参 | 出参 | 备注 |
|---|---|---|---|
| `POST /api/p2/jobs` | `{workflow, params, budget?, note?, parent?}` | `{job_id, state, params_hash}` | 唯一创建入口；服务端做 registry 校验与渲染 |
| `GET /api/p2/jobs` | `state, workflow, model, since, q, cursor, limit` | `{items[], next_cursor}` | 列表 |
| `GET /api/p2/jobs/<id>` | — | `{job, steps, artifacts[], cost}` | 详情/轮询共用 |
| `POST /api/p2/jobs/<id>/cancel` | — | `{state}` | 仅 CREATED/PROVISION/SUBMITTED 可取消 |
| `POST /api/p2/jobs/<id>/rerun` | `{overrides?}` | `{job_id}` | 复制参数，生成新作业 |
| `GET /api/p2/jobs/<id>/artifacts/<name>` | `?dl=1` | 文件流 | 路径白名单校验，禁止 `..` |
| `POST /api/p2/uploads` | multipart：`file`, `kind=source|mask` | `{upload_id, url, width, height}` | ≤20MB；magic number 校验；蒙版仅 PNG |
| `GET/POST /api/p2/presets` | `{name, workflow, params}` | `{items[]}` | 参数预设，存 `share/presets.json` |
| `GET /api/p2/share/<job_id>` | `sig` | 分享数据 | 无 token，签名校验 |

鉴权：内部接口要求 `X-DSH-Token`（或同源 cookie），与现有 `_token_ok` 一致；分享接口只认签名。

## 7. 代码落点（不破坏现有 fileserver）

```
webui/
  __init__.py
  pages.py      # 页面骨架 + 6 个页面渲染函数（纯函数，输入 dict → HTML）
  components.py # 组件函数（Badge/Field/Grid/Timeline…）
  assets.py     # app.css / app.js 源串（或读 webui/static/）
  api.py        # 写接口 handler（jobs/uploads/presets/share）
  static/
    app.css
    app.js
tools/webui/
  tests/test_pages.py   # 路由 200/关键节点存在/转义正确
  tests/test_api.py     # 提交/取消/重跑/上传校验
```

`fileserver.py` 只加路由分发（`/app/*`、`/api/p2/jobs*`、`/api/p2/uploads`、`/share/*`），页面与接口逻辑放 `webui/`，避免 1064 行的单文件继续膨胀。

## 8. 响应式与可访问性

- 断点：≥1280 双栏（参数 380px + 结果自适应）；768–1280 参数折叠为抽屉；<768 单列，结果优先。
- 键盘：Tab 顺序按"模型→参数→提交→结果"；`⌘/Ctrl+Enter` 提交；`Esc` 关闭弹层。
- 对比度 ≥ 4.5:1；状态不只靠颜色（徽章带文字）。
- 图片 `alt` 用 prompt 摘要；表单 `label for` 齐全。

## 11. 附：与"最小控制台"的差异

| 维度 | 最小控制台 | 本方案 |
|---|---|---|
| 页面数 | 1 | 6（创作/列表/详情/图库/注册表/分享） |
| 参数形态 | 表单输入框 | 七类字段 + 预设 + 随机/锁定 seed + 分辨率预设 |
| 结果 | 图片列表 | 网格 + 放大 + 下载 + 复用为下一轮输入 + 对比滑杆 |
| 追溯 | 无 | 状态机时间线 + 参数来源 + workflow/model 版本 + 分享签名 |
| 代价 | ~8h | ~40h（约 5 个工作日） |
