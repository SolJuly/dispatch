## 1. 方法与过程（含踩坑）

| 次序 | 结果 | 说明 |
|---|---|---|
| 1 | ✅ 有效 | 起机 57s → SSH 就绪 → 完整列目录。`/model` 已挂载（`MOUNT_OK`），得到 checkpoints 57 / loras 29 / controlnet 16 / ipadapter 16 / upscale 4。但当时 NVML 未就绪，ComfyUI 起不来，`/object_info` 没有取到 |
| 2 | ❌ Install Fail | 平台镜像安装失败，未计费，已删除 |
| 3 | ⚠️ 部分 | 拿到 counts + `inpaint` 目录 + Qwen 软链，但 `find` 扫 40T UPFS 把脚本拖住，超时被截断；该次原始输出被第 4 次覆盖，仅保留派生值 |
| 4 | ❌ SSH 中断 | 实例开机 2–3 分钟后 SSH 端口被重置（`Connection refused`），远端后台脚本没写出结果 |

**教训**：镜像首次开机后有一个重启窗口（约 2–3 分钟），SSH 会在窗口内被重置；盘点必须**在 90 秒内做完**或**等重启结束后再跑**，且远端命令不要用 `find` 扫 `/model`（UPFS 上极慢）。第 4 次已改成"后台 nohup + 完成标记 + 定点列举"，但撞上重启窗口。
