## 3. 三层回滚演练

### 3.1 代码回滚（`tools/p1/verify.py` → main 版）

```bash
cp tools/p1/verify.py /tmp/verify.p2.bak
git checkout main -- tools/p1/verify.py
# → CHECK_ORDER = ('decode','geometry','frames','size','black','params')   # freeze 消失
cp /tmp/verify.p2.bak tools/p1/verify.py
# → CHECK_ORDER = (...,'freeze',...)                                       # 已恢复
```
**结果：命令有效、可逆，恢复后与 HEAD 无差异。**

### 3.2 镜像回滚（删 `image.json` → 回落关键字）

| 状态 | `_pick_image(kind=video)` | `_pick_image(kind=image)` |
|---|---|---|
| 无 image.json | `ComfyUI基础镜像纯净版0.36.0` | 同左 |
| 有 image.json | `compshareImage-1x65o3j08tdw`（media） | `compshareImage-1x65ieja8ncj`（base） |

**结果：删文件即回落平台镜像，选层逻辑不影响闭环。**

### 3.3 队列回滚（删库重建）

```bash
rm reports/p2/queue.db*
python3 tools/p2/batchctl.py list   # → 队列为空
# schema_version = 2，自动重建
```
**结果：队列历史丢失但 job 事实仍在 `reports/p1/jobs/*/job.json`，产物与状态不受影响。**
