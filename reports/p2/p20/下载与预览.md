# P2.0 验收材料 · 下载与预览

> 公网入口：**https://123.207.74.155/pub/p20/**
>
> 由 nginx 直接静态提供（nginx 配置 `location /pub/ { alias /srv/dsh-pub/; }`），
> **不依赖任何临时后台进程**，容器重启后链接依然有效。

## 为什么换地址

之前的 `https://123.207.74.155/files/{TOKEN}/...` 是 nginx 反代到容器内
`127.0.0.1:8081` 的 `fileserver.py`。这个进程随会话启动、随会话回收，一旦被回收，
外网访问就是 **502**。现在改为把材料复制进 nginx 的静态目录 `/srv/dsh-pub/p20/`，
由 nginx 工作进程直接读盘返回，不再需要守护任何进程。

## 重新发布 / 自检

```bash
cd /root/智云视频工作流
python3 scripts/publish_public.py          # 重新复制 + 渲染 + 自检全部 URL
python3 scripts/publish_public.py --check  # 只自检
```

脚本内部会先 `mount -o remount,rw /`（容器根文件系统默认只读），再复制到 `/srv/dsh-pub/p20/`。

## 旧地址状态

`/files/...` 反代链路当前不可用（502）。要在部署机上长期恢复，需在**部署主机**上执行：

```bash
bash scripts/deploy.sh        # 同步 share/ + systemctl restart cs-files + 健康检查
```

本容器内 `systemctl` 的 D-Bus 不可达，因此无法在这里重启 `cs-files` 服务。
