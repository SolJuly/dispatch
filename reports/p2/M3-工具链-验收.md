## 1. `csctl pull` 目录探测 bug（D1：允许改主链）

### 修了什么（`tools/transfer.py`）

| 层 | 改动 |
|---|---|
| `ssh()` | 捕 `TimeoutExpired` → 返回 `(124, "TIMEOUT(Ns)")`，不再抛；新增 `retries` 参数（超时重试） |
| `_classify()` | 探测超时 30s→60s + 重试 1 次；仍超时 → **明确降级按单文件处理**并打印警告 |
| `pull()` | `probe()` / `_classify()` 收进 try，异常不再终结整条 pull |
| `pull_file()` | scp 超时不再抛，返回 False |

补丁形状与 `reports/p1/csctl-pull-目录探测bug.md` 的**方案 B+** 一致，另加 `pull_file` 的 scp 兜底（原方案未覆盖，实测会被注入的超时打到）。

### 单测（`tools/p2/tests/test_transfer_timeout.py`，5 条全绿）

1. `ssh()` 超时 → `(124, TIMEOUT)`，不抛
2. `ssh(retries=2)` 超时 → 调 2 次后返回 124
3. `_classify()` 超时 → 降级 `("file", [name], dir)`
4. `pull()` 探测超时 → 返回 False（不抛）
5. 正常路径回归：目录 / 单文件 / 通配符分类不变

> 真机「满载实例上 pull」本轮未做（当前无实例在跑，且 M1 已把 setup 归零，满载场景需要一次真实推理搭车）。单测已用 monkeypatch 完整覆盖超时路径，逻辑等价。

## 2. 视频/图片自动拼接（D5：post 步骤）

### 能力（`tools/p2/concat.py`）

| 场景 | 策略 | 实测 |
|---|---|---|
| 同参多段（codec/宽高/fps/pix_fmt/时基一致、无音轨） | concat demuxer + `-c copy` | 3×5.167s → **15.501s，0.35s 出片（44× 实时）** |
| 异参（如 24fps + 16fps） | scale+pad+fps 归一后 concat 滤镜 + libx264 crf18 | 单测：输出 24fps / 320×240 / 时长对 |
| 图片 N 张 → 网格 | 每格 scale+pad，行 hstack、列 vstack，末端 crop 去多余 gap | 4 张 → **2408×1604（=2×1200+8）**，尺寸精确对齐 |
| 坏输入 | 明确报错并指出是哪个文件 | 单测：`不存在：['missing.mp4']`，不产出半片 |

**统一 `-an`**（现有产物无音轨）；含音轨时显式降级重编码并告警。
**拼完必校验**：总时长 ≈ Σ输入 ±1 帧，不合格直接报错（不静默产出废片）。

### 集成（`tools/p1/run.py` 的 `post` 钩子）

- 位置：`PERSISTED` 之后、`RELEASING` 之前（守卫 G1 不受影响）。
- 声明：`job.json` 里 `"post": [{"op":"concat","inputs":["01-a.mp4","02-b.mp4"],"out":"long.mp4"}]`
- 产物写入 `artifacts/`，`manifest.derived` 追加每条结果（含 mode/duration/size）。
- post 失败只记录告警，不改变主产物 verdict。

离线验证：两段真实产物 → `long.mp4` 10.334s，`artifacts/` 里三份齐全。

### 单测（`tools/p2/tests/test_concat.py`，4 条全绿）

同参 copy / 异参 reencode / 图片 2×2 网格 / 坏输入。
